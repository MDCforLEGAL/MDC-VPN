MDC VPN for Windows - OpenVPN notice
====================================

This package bundles the unmodified OpenVPN Community client
(openvpn.exe and its shared libraries) so that the app can establish a
tunnel without a separate installation.

OpenVPN is free software, licensed under the GNU General Public License
version 2. Source code: https://github.com/OpenVPN/openvpn
Project website: https://openvpn.net/community/

The OpenVPN binaries are started as a separate process by MDC VPN; MDC VPN
itself is distributed under the Apache License 2.0 (see the project
repository).

WireGuard support uses the WireGuard for Windows client, which must be
installed separately: https://www.wireguard.com/install/
